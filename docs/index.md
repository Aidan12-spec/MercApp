## MercApp

## Enlaces del proyecto(Unidad 4)
- **Frontend(Netlify):** [https://mercapp-flores.netlify.app](https://mercapp-flores.netlify.app)
- **Backend(Railway):** [https://mercapp-production-f0c7.up.railway.app](https://mercapp-production-f0c7.up.railway.app)
- **Base de datos:** MongoDB Atlas

## Tecnologias utilizadas
- **Backend:** Node.js, Express, CORS
- **Frontend:** Vue.js, Vite, Axios
- **Base de Datos:** MongoDB

## Cambios
- Se implemento la arquitectura cliente - servidor
- Conexion corectamente a la base de datos Mongodb
- Configuracion de las politicas de CORS para permitir la comunicacion entre el backend(Railway) y frontend(Netlify)

## funcionalidades implementadas(Unidad 3)
  **Backend**
- **API Rest:** El servidor HTTP uneta con un ciclo CRUD(Get, Post, Put, Delete) desarrollaod con Node.js y Express.
- **Persistencia de datos local:** Cuenta con lectura y escritura mediante el modulo nativo fs de Node.js de un archivo plano(seed.json)
- **Manjeo de errores y codigos de estado:** Esta configuado con los estandares(200 OK, 201 Created, 400 Bad Request, 404 Not Found y 500 Internal Server Error)

**Frontend**
- **Desarrollo Vue 3:** La interfaz esta construido con la Composicion API y la sintaxis optimizada
- **Enrutamiento:** Cuenta con la implementancion de Vue Router con importanciones dinamicas a traves del import() para las vistas secndarias.
- **Persistencia del cliente:** Esta sincronizado de forma automatica al carrito con el localStorage del navegador.
